launcher

One launcher, three sites.

The same apps, palette and launch on mutaafaziz.com (a dock), digitalcraftai.com and cto.digitalcraftai.com (a button in the navbar). Press ⌘K, Ctrl+K or /.

    Skins

    Light, button
    Dark, sky accent
    Dark, copper accent

    Use

    <script src="launcher.js"></script>
<script>
  // a button you already have (the Digital Craft sites)
  Launcher.mount({ trigger: document.querySelector('#apps'), theme: 'dark', here: 'cto',
                   vars: { '--l-accent': '#C96E2C' } });
  // or a bottom dock (mutaafaziz.com)
  Launcher.mount({ mode: 'dock', here: 'mz' });
</script>
